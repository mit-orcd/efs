.efs/find - Search names recursively

Usage:
  .efs/find [-h] [--json] [-0] [-l] [--human-readable]
          [--sort {name,mtime,size}] [-r] [--time-style {iso,relative,full}]
          [--relative] [--match {exact,prefix,suffix,contains}]
          [--type {file,dir,symlink}] [--min-size MIN_SIZE]
          [--max-size MAX_SIZE] [--modified-after MODIFIED_AFTER]
          [--modified-before MODIFIED_BEFORE]
          [--modified-within MODIFIED_WITHIN]
          pattern

Arguments:
  pattern               Name pattern; matched literally

Options:
  -h, --help            Show this help
  --json                Structured results and snapshot details
  -0, --print0          NUL-separated paths
  -l, --long            Permissions, uid:gid, size, modification date and path
  --human-readable      Format long-list sizes as KiB, MiB, GiB
  --sort {name,mtime,size}
                        Name ascending (default), newest first, or largest
                        first
  -r, --reverse         Reverse the selected sort order
  --time-style {iso,relative,full}
                        Long-list dates: UTC iso (default), relative age, or
                        full UTC nanoseconds
  --relative            Paths relative to the directory containing .efs
  --match {exact,prefix,suffix,contains}
                        Match type (default: contains)
  --type {file,dir,symlink}
                        Filter entry type; symlinks are not followed
  --min-size MIN_SIZE   Minimum logical size, inclusive (bytes or e.g. 100MiB)
  --max-size MAX_SIZE   Maximum logical size, inclusive
  --modified-after MODIFIED_AFTER
                        mtime strictly after an ISO timestamp with timezone
  --modified-before MODIFIED_BEFORE
                        mtime strictly before an ISO timestamp with timezone
  --modified-within MODIFIED_WITHIN
                        mtime in the past duration (e.g. 2h, 7d); excludes
                        future times

Examples:
  .efs/find report -l --sort mtime
  .efs/find .log --match suffix --min-size 100MiB
  .efs/find '' --type file --modified-within 2d -0

Notes:
  Use .efs/help --extended for limits and requirements.
