started `efs-fuse` did not establish that policy. Candidate **`bc86327c6`**
makes four glibc arenas a fixed binary startup policy, before transport,

switch. Non-glibc allocators do not use glibc's per-core arena mechanism.

proved complete memory fix. It never trims memory or reduces a cache,
changes durability, bounds or the test's workload.
