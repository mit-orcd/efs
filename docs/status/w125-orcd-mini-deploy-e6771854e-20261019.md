## Live packing check

`scripts/w125_live_check.py` (committed in `c6f557213`, after the deployed
commit; test-only) writes 20,000 deterministic files of 100 B to 16 KiB in
200 directories and verifies them byte for byte.

1. **Write** from node9900: `python3 w125_live_check.py write
   /data1/efs/orcd-mini-mnt/w125-live 20000`, 46.8 s.
2. **Pack:** the packer ran at the busy rate during the write and finished
   about 3 minutes after it. Per node: 1,337 MB → 78 MB of `data/`, 1,072
   segment files. A sampled file's chunk row is a packed reference
   (`raft-getchunks`: `packed segment=… group=0 offset=44852 len=4096`).
3. **Verify** from node9901: `verify … 20000`: bad 0 (22.4 s).
4. **Delete** from node9900 (`rm -rf`, 7.8 s): `data/` back to the 9 MB
   baseline within 25 s on all nodes. Eight segments stayed, all live:
   they held files the two-client suite leaves behind (its parent
   directory, 147 files) and a manual test directory. After removing those,
   no segment file remained on any node within 15 s.
