# A12 closure: one supported behavior, every selector accounted for (Oct 25)

**Current-source audit, Oct 28:** [Task Z](stage1-decision-sheet-20261028.md)
pins devel `9e4d66a8c`: 139 readers, 33 refused names, no new A/B selector;
expiry compiled into every build under D43, READ_VERIFY replaced by built-in
client hashing. Historical counts/branch states and compiled-out expiry prose
below describe their dated source, not the current candidate. Task Z is not
full retained-path or topology qualification.

**Verdict: PASS (scoped to A12's audit).** Every A/B behavior selector the
[A6 inventory](a6-settings-inventory-20261024.md) found is removed with its
alternative implementation and refused at startup, except `EFS_TRANSPORT`,
which is a justified A8 support dimension. No unexplained experimental,
legacy or correctness-policy toggle remains: every `EFS_*` variable the
product reads has an inventory row whose kind is one of five retained kinds,
and `scripts/env_inventory.py --check` (in `make test`) now fails on any
other kind. **This is not correctness evidence for the retained paths.**
Removing a flag proves only that the alternative is gone; the paths that
remain are qualified by the gates listed [below](#what-qualifies-the-retained-paths),
most of which are NOTRUN on real hosts.

## No unexplained toggle remains

- **No A/B selector is read.** A product build reads 77 variables: 9
  deployment inputs, 33 numeric tunables, 34 observability switches and 1
  tool input. Since this branch, `scripts/env_inventory.py --check` fails
  in `make test` if a read variable has no row or a row of any other kind.
  It names the variable (`tests/test_env_inventory.py`: a row reclassed as
  `A/B behavior selector`, and a row with no kind, both fail).
- **No experimental or legacy switch.** The removed selectors and old CLIs
  are refused by name, never ignored. A stale launch file therefore stops
  the daemon instead of running a different configuration
  (`test_env_removed.py`, `test_direct_io_required.py`,
  `test_cli_surface.py`). Retired wire types close the connection
  (`EFS_MSG_IS_RETIRED`).
- **No correctness-policy toggle.** Read verification, direct I/O,
  membership persistence, unmount revoke and Raft batching are each built
  in. Fault hooks that could change correctness exist only in `EFS_FAULTS`
  test builds; `--check` fails a fault hook read outside `#if EFS_FAULTS`.
- **The A6–A12 removals left no dead code behind.** See the
  [sweep](a12-hygiene-20261025.md#dead-code-sweep-item-1): two orphaned
  functions and several unread fields were removed, none tied to a toggle.

Open for A8 (not A12): the 33 numeric tunables still need a qualified
built-in value or bound each, and the four `#ifndef` defaults could become
plain constants. Neither is an A/B selector.

## What qualifies the retained paths

Flag removal alone is not correctness evidence. The retained behavior is
qualified by these gates:

- [A11 reduced qualification matrix](a11-qualification-matrix-20261024.md)
  and the [Stage 2 gates](stage2-gates-20261024.md) (`scripts/qualify.py`):
  TCP/RDMA × 3, 4 and 5 distinct hosts. **NOTRUN on real hosts**: no
  distinct-host topology can form today (A4). Loopback-3 PASS only.
- D42's conditions on direct I/O: reads, writes, packing, `fsync` and
  recovery on clusters, **NOTRUN** (the parent's live qualification). Unit
  and loopback tests pass ([A7 evidence](a7-removals-20261024.md#limitations-and-remaining-gates)).
- [READ_VERIFY GET-path audit](read-verify-audit-20261024.md): the built-in
  re-hash is the one tested behavior.
- [F1 memory and concurrency gates](f1-memory-concurrency-gates-20261025.md):
  leak, ASan/UBSan and TSan over the candidate.
- A9 leader placement: elections alone, measured on loopback 3, 4 and 5
  members in the [hygiene evidence](a12-hygiene-20261025.md#a9-leader-placement-item-2).
  The real-host measurement under A11 load is the parent's.
- `make test-all` on this branch: see the
  [gate](a12-hygiene-20261025.md#gate).
