# K37: Packed segment with a missing fragment is never re-protected

- State: VERIFY
- Blocks alpha: unstated
- Kind: durability, alpha blocker

## Summary

- Cause: Fixed: no segment rebuild existed; a durable degraded mark per segment now drives a leader rebuild from the other two fragments.
- Owners: `EFS_MD_CMD_PACK_DEGRADED`
- Reproducer: `tests/test_k37_segment_rebuild.py`, `tests/test_k33_payload.py`.
- Invariant: Every acknowledged write survives any single-member loss once protection is restored; a packed read with fewer than two fragments is EIO.
- Owed: Distinct-host segment rebuild acceptance (multi-host, RDMA, orcd-mini).

## Item

A packed segment (D38: one 2+1 stripe holding many small files) with a missing fragment was never re-protected: K36 can only count referenced segment fragments that are missing, and no segment rebuild existed, so such a segment stayed one loss away from losing every packed file in it (the alpha 1.0 rule: every acknowledged write survives any single-member loss once protection is restored)
