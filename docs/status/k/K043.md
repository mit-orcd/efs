## Item

The new leader refused the publication unit NOT_PRIMARY and decided the abort (`coordinator lost its group`), but its 57 PREPARE intents on shard 1 stayed until `txn-recover ... age=8.1s -> ABORT`; the client's resend 7 s later lost its CAS against them (`report-split stale=1 rc=-14`), `report-resolve ... outcome=partial rc=-14 first_rc=-13 stuck=unrecorded (an apply-time CAS loser)`, and `flush-meta` returned BUSY to the application 0.13 s before recovery aborted the intents. Retained stores: all 512 acknowledged versions and 3,379 appends exact on two fresh readers; only the failed write's file holds mixed bytes. The first crash event of the same run (3,480 s) passed
