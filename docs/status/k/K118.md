# K118: Local fragment rebuild skipped the degraded-mark check and retire mark

- State: VERIFY
- Blocks alpha: no
- Kind: server / rebuild onto the rebuilding node (rest of K61)

## Summary

- Cause: Fixed in wave 79: the local branch of `dg_put_fragment` wrote a rebuilt fragment directly; it now calls `server_rebuild_put_parts`, the body of the wire path's `server_rebuild_put`.
- Owners: `src/server/raft_host.c` (`dg_put_fragment`), `src/server/put_upload.c` (`server_rebuild_put_parts`)
- Reproducer: `tests/test_rebuild_local_authority.py` (extracted code with stubs; fails on the parent commit).
- Invariant: A rebuild onto the rebuilding node itself passes the same degraded-mark check and writes the same retire mark as one that arrives over the wire.
- Owed: A real run of a rebuild whose target leads the mark's group (only stubs ran); the length check answers INVAL on an export with a non-default chunk size until a client PUT sets the geometry.
