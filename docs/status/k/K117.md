## Disposition

FIXED, blocks alpha: no (Nov 11, W123 port `645c3d03a`, merged in wave 79, [page](../2026-11/w123-ports-20261110.md)): the sweep removes a temp file through `server_put_session_recover_tmp` in `src/server/put_fence.c`, under that UUID's seal mutex, which a seal holds from before it creates the temp file until its rename; a temp file seen under the mutex therefore has no live owner.
