# K32: ior easy write fell from ~1.3 GiB/s to ~0.36–0.5 GiB/s after the fourth wave; reads unchanged

- State: DECIDED
- Blocks alpha: no
- Kind: performance regression (Stage 3 by D50)

## Item

ior easy write fell from ~1.3 GiB/s to ~0.36–0.5 GiB/s after the fourth wave; reads unchanged. K14 makes every multi-chunk FUSE write its own cross-group transaction (~20 Raft entries per 1 MiB write, from 0.1); K13 adds ~9 (per-object ticket admission and settle). Latency-bound, servers mostly idle.
