## Findings and fixes

- **Membership and discovery partial output:** rejected records could
  overwrite caller output. Decode locally and publish only after validation.
  Exact short-membership and zero-port discovery bytes are regressions.
- **Ticket-batch partial output:** an invalid second ticket could leave the
  first ticket in the caller's array. Batch and ordered SETTLE parsing now
  validate a local array before publishing array/count. Raft uses these same
  decoders.
- **Unaligned declaration access:** Intel1 UBSan reported typed access to an
  unaligned byte buffer. Parsing and refusal diagnostics now use `memcpy`.
  The exact malformed unaligned declaration is a regression.
- **Fragment verification partial output:** an identity mismatch could expose
  a parsed digest before successful identity verification. Only success now
  publishes the digest. The diagnostic field still names the mismatch, as
  documented; every mismatch unit case checks unchanged digest output.
- **Malformed membership error replies:** negative replies could ignore a
  nonzero record length or trailing bytes. Require the exact error header,
  with no record. Keep genuine server errors distinct from malformed input.
- **Unknown declared frames silently ignored:** default dispatch now closes
  the connection with a bounded diagnostic. The private live gate checks
  refusal on every member and both metadata groups; unsupported proposals
  follow the documented follower redirect, add no log entry, and do not halt
  a group. A subsequent real CREATE commits.
- **Remaining named boundaries:** transactional pure validators cover store
  identity, HELLO, recovery page envelopes, audit request/reply, degraded and
  recovery marks, pack-degraded, D31 drain, PUT upload header and E2 cleanup
  probe. No current wire/record encoding changes.
- **W155 scope:** the receipt table is an in-memory state machine, not a byte
  decoder. Its target checks arbitrary-key lookup misses leave output
  unchanged; existing receipt/concurrency gates remain in the suite.

Test defects were also corrected: the extracted drain harness needed the
new decoder declaration; sanitized source copies must exclude active FIFOs,
runtime trees, symlinks and private account files. The copy regression covers
top-level and nested FIFOs. Earlier Makefile placement and live ReadIndex
fixture mistakes were fixed. The truncated 72-command run is invalid evidence
