# W84: complete lane envelope acceptance — Oct 7, 2026

Implementation commit: `51c8bf12`.

The next coherent package after W59/W67 is W84. This follow-up repairs
full-lane namespace admission and PREPARE command sizing. It does not close W84.

## Change

The transaction envelope holds 144 distinct participants: 64 directory lanes,
64 ancestry shards and fixed parent/dentry/op-id participants. Every lane and
ancestry predicate is retained. PREPARE buffers use the largest supported
participant/key/payload combination, with validation before encoding. Previously
these paths encoded into 512-byte arrays before testing the result's length.

The count field stays one byte. Existing records with up to 64 participants
remain readable. Upgrade all participating servers together before admitting
larger transactions; older binaries cannot recover larger pending intents.
No shared service rollout was performed: tests use private four-node TCP stores
on both NUC storage devices.

## Acceptance

Maximum participant serialization/canaries, largest-key PREPARE with exact CAS
payload, full-capacity prepared-intent visibility/recovery, and ancestry boundary
helper checks pass. The full Linux `make test` passes.

Direct and buffered private fixtures exercise 64 historical lanes, successful
empty-directory rmdir and replacement, and authoritative inode preservation
across full restart. They also cover opposite directory-move races, physical
GC, restart and POSIX. Each mode passed 216 single-client tests (one mmap skip) and 64 two-client
tests, with zero failures. Physical inventory, orphan/GC queues and quota
are empty after restart; late PUT is fenced on all four members. Both harness
processes exited zero. Detailed final results are retained in
[the evidence directory](../../results/measure/20261007-w84-envelope/README.md).

Initial live runs were interrupted after discovering the command buffer defect;
they are retained as interrupted attempts, not counted as passing gates. The
fixed runs start fresh stores and use the corrected PREPARE buffers.

## Remaining

W84 remains open because the separate 64-hop ancestry walk still permanently
refuses deeper supported operations. Coordinator failure around PREPARE/decision
at the boundary is also unaccepted. Restart after successful completion is not
that failure gate. The open package count remains 46, with 10 implemented or
partial packages awaiting gates.
