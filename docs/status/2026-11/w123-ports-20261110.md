## What each defect is

1. **L0 order after a restart (`c88fa14ec`).** An async L0-only fold takes its
   output file number at its first emitted row, after it released the store
   mutex. A flush that runs in that window gets a lower number although its
   rows are newer. Publication puts the flush ahead of the fold output, and
   the MANIFEST persists that order. `manifest_load` then sorted L0 by number,
   so after a restart the folded, older values and tombstones won.
   `tests/test_kv_fold_reopen.c` produces this with a real fold and a real
   flush and kills the process: on unmodified devel the reopened store returns
   the older counter value (assertion `tip==111` fails). It needs a file-cap
   fold to overlap a flush; how often that happens in a cluster was not
   measured.
2. **Local fragment rebuild (`09e54f897`).** When the rebuilding node is
   itself the target, devel wrote the fragment with `efs_store_put` directly:
   no check of the degraded mark through the mark's group, and no retire mark,
   which `fragment_retired_since` reads as "not retired". This is the part of
   K61 that the wire path fix did not cover. A refusal is now returned as it
   is; the caller skips the node for the pass and counts a rebuild failure.
3. **K36 sweep against a live seal (`645c3d03a`).** The ledger sweep runs in
   the background after an unclean start and unlinked every
   `meta/put-session/*.tmp.*`. A seal in progress then failed its rename with
   `EFS_ERR_IO`. What that IO verdict does to the member when it comes from
   the apply of FENCE_LOC was not traced.
4. **Directory rename (`1f4ab2a7e`).** The rename is committed on the server
   before the mirror is updated; marking the directory dirty left an entry the
   next report pass had to drain. No symptom on devel is claimed.
5. **Prefix (`14a476c77`).** A speed change with the same result.

## Limitations

- The local rebuild now submits the mark check to its own host from the
  rebuild thread. That real path ran only against stubs here; nothing shows
  that a gate test rebuilds a fragment onto the rebuilding node itself.
- With the load-time sort gone, the MANIFEST writer is the only authority for
  L0 order. `kv_manifest_write` is the single writer in `src` and `tools` and
  emits `l0[]` in array order (read, Nov 10).
- The seal sweep now refuses a temp name that is not `<32 hex>.tmp.*` where
  devel unlinked it. `put_fence.c` is the only writer into
  `meta/put-session` and creates exactly that shape (read, Nov 10).
- The review judged commits by reading; only the six ports were built and run.
- No distinct-host or RDMA run, no live cluster run, no throughput run.
- The three defects 1 to 3 have no K row. This branch adds none: K rows are
  the coordinator's, and its wave in flight edits the register.
- How often a fold overlaps a flush on a running cluster is unknown; the
  branch's baseline workload had no file-cap fold at all.
- The branch `devel-w123-recovery` received commits on Nov 10; this review is
  of head `d4b0b5aa0`.
