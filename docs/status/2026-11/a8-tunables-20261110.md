## Method

For each name: its reader in `src/` and `include/`, its default and bounds,
and every setter in `tests/`, `scripts/`, the `Makefile`, `~/git/devops`
and `~/git/cluster` (read only). A setter counts only if it can still run at
HEAD: scripts that start efsd with `--node-id` (refused since K33) or set a
name already refused (A6/A7) cannot, and are named as such. Then one
disposition:

- **(a) built in**: nothing that can run sets it, and the default is the
  value the tests and launches run. The reader goes, the name joins
  `removed_env[]` (`src/common/common.c`), the row moves to the page's
  refused-at-startup table.
- **(b) test-only**: only tests set it. Read only in `EFS_FAULTS` builds
  as `EFS_FAULT_<name>` when a daemon test sets it through
  `tests/faults/efsd`, or a test hook with no environment name when a unit
  test runs the code in-process. The old name is refused.
- **(c) justified**: a concrete operator need and the tests that cover its
  bounded range.
- **(d) for the user**: removal would change a deployment the user runs
  (orcd-mini, orcd-test).

Reproduce the audit:

```bash
python3 scripts/env_inventory.py --check docs/how-it-works/settings.md
python3 scripts/env_inventory.py --uses EFS_PACK_MIN_AGE_MS EFS_CLIENT_META_MB
grep -rnw EFS_RAFT_APPLIED_INTERVAL_MS ~/git/devops ~/git/cluster
```

The justified rows, with what their tests cover, are on the
[inventory](../../how-it-works/settings.md#client-budgets-and-timing-efs-fuse):
the five client memory budgets size efs-fuse on a host (a small client
lowers them, a large metadata working set raises `EFS_CLIENT_META_MB`), the
query refresh interval trades catalog freshness against full-shard rebuilds
(a large namespace lengthens it; the query gates shorten it), the
checkpoint cadence trades one small write per group per interval against
replay after a crash, and `--writers` sizes durable I/O to the host's
devices. Each is bounded in code; the tests cover the floor and the default,
not the top of the range (a limitation, below).

  (product efsd, `EFS_PACK_MIN_AGE_MS=500`)
  now stops at startup with the refusal; it reproduces at its own tested
  commit.
  The W125 and D25 scripts (the W125 packer runs start their cluster with
