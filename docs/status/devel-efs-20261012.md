## Relationship to small-file packing

W91 command invocation, W108 NSS owner/group display and W92 namespace queries
operate on logical files and metadata; they do not require packed data storage.
Logical file counts, lengths and ownership must be identical for an equivalent
namespace regardless of storage layout. W109 contention may share infrastructure
with packed uploads, but ordinary files can reproduce and qualify query behavior.

Packing-specific integration is separate: shared-fragment physical accounting
must avoid counting one fragment for every member file; deleting or overwriting
one member must preserve the other members while logical query counts converge;
packed publication and shared-fragment GC must not block query progress. Those
combined gates require packing enabled and remain NOTRUN/excluded here. Passing
this branch's ordinary-file query tests cannot qualify small-file coalescing,
packed reads, shared-fragment GC or packed physical-space accounting (W95).
