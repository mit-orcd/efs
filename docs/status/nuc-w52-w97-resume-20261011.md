## W52: bounded shared completion transaction

and prepares their original exact images in one transaction. Planned reads and
ordered reservation scans see the earlier planned completions, so the final
frontier and lane-barrier changes match sequential completion. The session and
inode guards are shared, every applied PREPARE verdict still precedes COMMIT,
and ambiguous COMMIT acknowledgements remain recovery work, never ABORT.

The existing per-shard image bound is unchanged. The host shrinks a batch when
the active-lane distribution cannot fit it, eventually using the original
one-reservation path. Collection is bounded; no existing lane/fencing predicate
is removed. No materialized mutation occurs if collection of a later range fails.
