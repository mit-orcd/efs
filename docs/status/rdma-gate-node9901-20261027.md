## Corrections under qualification

- **K48, product:** handler payloads began five bytes into a malloc allocation;
  GETATTR's typed pointer was unaligned. UBSan in the failed daemon log names
  `src/server/handler.c:1034`. Dispatch now slides the payload to the aligned
  allocation base without another allocation or dropping the assembly charge.
  The wire format is unchanged. The extracted original dispatch block fails
  under UBSan on the alignment access; the fixed block passes for small and
  64 KiB payloads (`test_rdma_handler_alignment.py`).
- **K49, product:** an already-running detached heartbeat can access expiry/Raft
  status during host destruction. TSan names `g_host`, its expiry-status load
  and shutdown's clearing store. The heartbeat is joined before host teardown
  and pool close, with a stop recheck after sleep; host unpublication is atomic.
  `test_heartbeat_shutdown.py` holds an in-flight observer across shutdown and
  proves the join waits; failed startup and repeated stop are covered too.
- **Provider receive handoff:** mlx5 inline CQEs may copy receive bytes during
  `ibv_poll_cq`, while CPU reads precede repost through the separate owner.
  The hardware ownership order was not represented as CPU synchronization.
  Polling and repost now share a per-device mutex across only their nonblocking
  provider calls, never decoding, registry work, sends or waits. This makes the
  ownership handoff explicit without race suppressions. `test_rdma_handoff.py`
  exercises both provider calls and verifies the lock is released on errors.
  Real TSan and load/performance evidence is still required.
- **Harness:** a failed `Mount` constructor never entered the caller's cleanup
  list, leaving four pre-mount clients alive after ASan failure. It now closes
  and joins its owned client before rethrowing, retaining the fixture and log.
  `test_k33_setup.py` covers early exit and timeout. The four original clients
  were stopped by verified executable and private-path identity; stores stay.

No application deadline was increased, no error was ignored, and no new product
setting or A/B mode was added. These changes are current-format only.
